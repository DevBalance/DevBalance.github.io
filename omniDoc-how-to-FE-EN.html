What omniDoc. is (and is not), and how to use it in the basic environment

omniDoc. is a tool for intelligently searching and interpreting content from a large number of different file types in your library, project folders, or SharePoint (PDFs, Word documents, scans, and emails).

I can upload confidential materials to the omniDoc. knowledge base – whether sensitive project data (for example, details of private transactions or information subject to confidentiality requirements) or personal data (for example, national identification numbers, dates of birth, or health information). Data is stored and processed on confidential servers.



Example

omniDoc. may, for example, contain dozens of PDFs with materials for the construction and outfitting of a new hall – designs, visualizations, contracts, documentation, delivery deadlines, requirements, supplier materials, and more.

With omniDoc., I can ask “What is the delivery date for the insulation?” or “List all the key dates in a table, including the expected invoice amounts for the corresponding periods (according to the quotations).”

omniDoc. is not ChatGPT over the internet

omniDoc. does not generally search the web for answers. It primarily works with the documents in its sources, which are prepared by your team or company. Its purpose is not to generate general knowledge, but to help you navigate your own materials.

omniDoc. is not yet designed for long conversations

omniDoc. delivers its best results in the first response. Instead of developing lengthy discussions, it is better to ask a question, search, and use the result.

omniDoc. does not know everything

A lawyer, designer, or tax adviser is still responsible for the professional conclusion. omniDoc. helps you quickly find relevant information, connections, and evidence in the sources, but it does not make decisions for you.

omniDoc. is not an image generator

omniDoc. understands images (it can “see” them in the sources), but it cannot generate images. Therefore, it cannot (yet) answer a request such as “Draw a map of the supply chain based on the underlying contracts for situation XXX.”

How should I use omniDoc.?

Chat interface

omniDoc. has a simple chat interface – a basic input for a question or prompt and a response window.

Asking a question and working with the result

The main and most common use is to enter your question and work with the result in the main response window.

In the left column, you can select collections or knowledge sources if, for example, you want to limit the search to a specific set of documents.

Documents found

The right column contains links to the documents found. By clicking them, you can view them in a preview, in a full Edge browser window, or download them.

It is practical to “open the documents in a split window” in Edge.

Basic rules for your questions

omniDoc. first searches the uploaded knowledge for document passages relevant to your question and only then creates an answer from the content it finds. A more precise question therefore usually leads to more accurate search results, better use of the sources, and easier verification of the result.

Say exactly what you are looking for

Instead of a general question such as “What is in the contracts?”, use a more specific request: “What are the notice periods, contractual penalties, and termination conditions in the contracts?”

Specific names, topics, people, companies, reference numbers, or document sections help omniDoc. find the right materials.

Provide the necessary context

If your question could be interpreted in several ways, add details such as:

  • the name of the project, contract, or company,
  • the type of document,
  • the period being examined,
  • the specific part of the documentation,
  • the situation for which you need the information.

Example: “Find changes to the completion date made in 2026 in the documentation for the Kitchen Renovation project.”

Focus on one main task per question

It is helpful to divide a complex request into several steps:

  • “Find the documents containing the contract termination conditions.”
  • “Compare the conditions in the contracts found.”
  • “List the main differences in a table.”

This gives you clearer answers and lets you check the sources used as you go.

Specify what the output should look like

For example, you can request:

  • a brief summary,
  • a list of key points,
  • a table,
  • a timeline,
  • a comparison of documents,
  • a draft text for an opinion or report.

Example: “Compare the supplier quotations for the Kitchen Renovation project in relation to the changes to the completion date made in 2026. Provide a table with prices, delivery dates, warranties, and the main reservations.”

Request an answer based only on the available documents

For important tasks, explicitly write: “Answer only according to the available documents. If you cannot find some information, that is not a problem; state this explicitly.”
